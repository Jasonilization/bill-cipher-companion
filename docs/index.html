What they do

Roam everything

Top-down strollers cross the whole screen. The Knight and Hornet leap between windows, wall-slide, climb. Flowey stays planted, because flower.

Study your apps

Per-character commentary for every app — generated through their own ChatGPT session, no API key, morning to night.

React to you

App launches, incognito windows, trash, clipboard, weather, time of day — each with in-character lines and animations.

Press buttons

Occasionally leaps onto a background window's yellow minimize light and actually minimizes it. Can also nudge windows aside (opt-in).

Talk back

Right-click → Talk. Every character has its own persona — sans types lowercase, Papyrus is VERY LOUD, the Knight speaks in lore tablets.

Keep you company

Idle beats, showcase performances of the whole sprite sheet, companions that wander and banter with each other.

Platforms

✓ macOS 14+

Native and first-class. Download it right now.

✓ Windows

Electron port in desktop/ — self-tested on Windows 11; installers build with npm run dist:win.

◐ Linux

X11 via the same Electron port. Untested — build with npm run dist:linux and tell us how it went.
